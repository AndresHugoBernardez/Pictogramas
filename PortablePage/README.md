# Portable Page

**Run PictoWriter offline, without installation or an Internet connection.**

### Requirements
- `index.html`
- The complete `data` folder and its contents.

### How to use
1. Download or copy the `PortablePage` folder.
2. Keep `index.html` and the `data` folder together.
3. Open `index.html` with any modern web browser.

That's it! No server, installation, or Internet connection required.

**Total size: less than 25 MB.**
